# AI Engineering: Track Plan

**Track:** AI Engineering

**Arc:** Takes a Python developer from making LLM API calls to building, evaluating, shipping, and maintaining an AI application, with retrieval, tool-using agents, and a guided final project.

**Audience:** Developers, software engineers, and data practitioners who are comfortable with Python and have tried an LLM, but have not shipped an LLM application.

**Format:** 16 courses, typically 2-3 hours each. Most courses have 6-7 lessons; the standalone MCP course retains its reviewed five-lesson outline. Lessons are approximately 20-25 minutes. All courses combine theory and application.

**Exercise environment:** DataCamp supplies model API access, local datasets, and the required local services. Learners do not need external subscriptions or accounts. Examples use a conference support assistant; the capstone transfers the same skills to invoice review. Model and framework choices support the concepts being taught.

**Status:** Draft adapted from the reviewed curriculum to the DataCamp brief. Runtime resource availability and the proposed package pins require validation in DataCamp's AI tutor environment.

**Scope note:** Agent frameworks and MCP remain separate courses. The 16-course sequence exceeds the brief's requested 12-15 courses and should be confirmed with DataCamp.
