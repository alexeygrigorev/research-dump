# DRAFT - DataCamp AI Engineering track plan

**Track**: AI Engineering

**Arc**: Learners build a conference speaker support assistant with OpenAI, retrieval, LangChain and LangGraph, then test, trace, evaluate, and deploy it. They apply the same skills to an invoice review capstone.

Status: **Draft for review.** The track uses the AI Engineering Field Guide for role and skill priorities and the AI Engineering Buildcamp for practical exercises.

## Market basis (AI Engineering Field Guide, 9,760 jobs)

Every stage and technology choice in this track reflects what employers actually require in 9,760 AI Engineer job postings (Feb-Nov 2026):

- **Applied integrator role, not model research**: 97.4% of postings are applied/production (only 2.6% research). Within AI-First roles (68.9% of the market), the **integrator stack** (RAG, agents, APIs) rose from 80.0% in February to **91.7%** in November, while the trainer stack fell from 37.5% to 27.2%. Fine-tuning is a primary responsibility in only 3.2% of AI-First roles and absent from responsibilities in 86.0%.
- **Full-stack beyond GenAI (86.9%)**: Python is mandatory (71.6% overall, 75.9% AI-First), followed by **GenAI + Ops** (71.0% of AI-First; across all jobs **CI/CD** 36.9%, **Docker** 24.2%, **Kubernetes** 23.6%; within AI-First CI/CD 36.7%, Docker 25.2%), **GenAI + Web** (59.2%: APIs 2,515 jobs, REST APIs 1,630, **FastAPI** 928, React 1,373), **SQL** (14.6%, rising 11.1% → 14.9%), and cloud (**AWS** 39.3% overall / 41.8% AI-First > Azure 29.7% > GCP 29.1%).
- **RAG + Agents are the core**: **Agents (any)** appear in **56.2%** of all jobs (**74.0%** AI-First) and **RAG** in **40.1%** (**56.0%** AI-First). Jobs requiring *both* RAG and agents jumped from 33.1% to **51.0%** of AI-First postings.
- **Standard agent & retrieval stack**: **LangChain** (21.1% overall, 76.8% of framework adopters) and **LangGraph** (14.4% overall, climbing 7.4% → 15.2% and 37.7% → 71.0% among framework adopters) are the #1 co-occurring pair (3.5x lift). **MCP** (15.6%) is the fastest-rising named skill (9.9% → **20.4%**, +0.94 pp/scrape), followed by **Function Calling** (15.1%, 9.6% → **18.5%**). **Vector Databases** (2,201 jobs) and **PostgreSQL** (1,020 jobs; `pgvector`) lead data storage.
- **Evaluation is the differentiator**: **61.8%** of AI-First roles require evaluation skills (rising 55.9% → **69.3%** in November), and Evaluation & Testing appeared in **79.0%** of November responsibilities (+9.6 pp). LLM-native eval tooling (LangSmith, Langfuse, Guardrails, LLM Evaluation) rose 26.7% → **34.5%** while classic MLOps declined, and **Guardrails** rose 10.2% → **17.5%**.
- **What the job is (responsibilities, 1556dcb2)**: building systems 96.0% of jobs, deploy/production **77.8%**, evaluation and quality **71.3%**, monitoring/maintenance **63.8%**, integrating APIs and services **55.8%** (self-hosting models only **3.1%**), agents **53.3%** (55.8% in November), RAG/retrieval **41.1%**, security and compliance **38.8%**, data processing **23.2%**, prompt engineering **21.5%** (22.8% in November), fine-tuning only **11.0%**.
- **Real use cases**: Automating manual workflows (**58.8%**), internal operational efficiency (**57.5%**), agentic systems (**49.9%**), finding information in company data (**32.5%**; 28.3% → 31.7% Feb to Nov), and document processing (**13.3% → 16.0%**), while consumer-facing Q&A (-13.8 pp) declined. The top domains are finance (3,877 mentions), healthcare (2,380), legal/regulatory (1,798), education (1,349) and cybersecurity (1,317).

## Learning path and portfolio alignment

The AI Engineering Field Guide informs the sequence and the skills learners demonstrate in their portfolio.

| Field Guide block | Track courses |
| :---- | :---- |
| LLM fundamentals | 1 |
| Retrieval, chunking, and document processing | 2–4 |
| Agents, MCP, and workflow patterns | 5–8 |
| Python projects, testing, tracing, evaluation, and guardrails | 9–13 |
| CI/CD and Kubernetes | 14–15 |
| Portfolio project | 16 |

The track assumes working Python. The capstone applies the Field Guide portfolio checklist to a reproducible invoice review assistant with tests, an evaluation set, trace evidence, and a README documenting trade-offs.

## Exercises adapted from the AI Engineering Buildcamp

Learners start with a short excerpt from a fictional conference speaker handbook, then build retrieval over the same handbook. The speaker support assistant adds a rehearsal schedule and a simulated ticket workflow, then becomes the system learners package, test, trace, evaluate, and guard. Kubernetes exercises deploy the read-only question-answering route. In the capstone, learners work from a separate set of fictional invoices, supplier agreements, and purchase orders.
