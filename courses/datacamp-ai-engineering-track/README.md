# DRAFT – DataCamp AI Engineering track plan

**Track**: AI Engineering

**Arc**: Takes a developer who has called an LLM API a few times through RAG, retrieval quality, agents, testing and evaluation, monitoring, CI/CD and deployment, ending able to own an LLM-powered application, including an agentic one, from design to production.

Status (2026-11-12): **DRAFT for Alexey's review.** Not submitted. Assembled from Alexey's two courses; he has not yet read or edited it.

Sources: LLM Zoomcamp (github.com/DataTalksClub/llm-zoomcamp, repo state 16 Sep 2026) and the AI Engineering Buildcamp (Alexey's Maven course; repo ai-engineering-buildcamp, curriculum.md). Abbreviations in the source map: LZ = LLM Zoomcamp path, BC = Buildcamp path. Lessons marked 'new' have no lesson in either source.

Package versions are the minimum versions pinned in the two course repos. 'version TBC' means the package is not pinned in the source material and no version was invented.

| 7 | [Agent Frameworks, Tools and MCP](courses/07-agent-frameworks-tools-and-mcp.md) | 3. Agents | After writing the loop by hand, learners move to a framework.
