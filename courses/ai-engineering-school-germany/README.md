# AI engineering school in Germany

**Working research and launch plan · updated 9 November 2026.** Owner: Alexey Grigorev. Target: a first live-online cohort in April 2027, potentially funded through Bildungsgutschein, developed alongside the existing education and community business.

## Current direction

The first iteration is to be taught and run by Alexey himself. **No employee or teaching-assistant hire is planned now.** First use the existing network to compare demand for three different learning needs:

1. **AI-assisted software engineering / agentic development:** people who already code and want to use coding agents to change, test and ship software.
2. **AI application engineering:** people who already code and want to build reliable applications with LLMs, retrieval and tools.
3. **Programming foundations with AI:** beginners and people who need a stronger coding base before advanced study.

**Beginners and career changers remain in the research.** Career change does not imply no programming experience. Segment by demonstrated capability as well as goals, availability and funding route. Greater support needs affect the delivery model; they do not establish that demand should be ignored.

The latest priority is to identify useful project expenditure that can lawfully reduce **2026** taxable profit. The accounting method is not yet confirmed. Under EÜR, genuine advances for ordinary business services in 2027 can potentially be deductible when paid in 2026. Bilanz, capital assets, security deposits and other exceptions require different treatment. The detailed [2026 expense plan](2026-expense-plan.md) is the place to make payment decisions.
