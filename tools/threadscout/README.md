# ThreadScout

**Персональный радар Reddit и Hacker News для Alexey Grigorev.**

Находит подходящие обсуждения → связывает их с твоим реальным опытом и материалами → присылает карточки в Telegram → сохраняет твой ответ. Python 3.11+, SQLite, стандартная библиотека. Новые платные SaaS и OpenAI API не нужны для базовой версии. Существующая подписка Codex используется опционально, в пределах её лимитов.

## Статус первой версии

| Возможность | Что готово |
|---|---|
| HN | Поиск публикаций/комментариев через Algolia; проверка через официальный Firebase API |
| Telegram | Личный чат, карточки, контекст, справка, свой ответ, копирование, отложить/пропустить/готово |
| Мини-редактор внутри Telegram | HTML + локальный сервер + проверка Telegram initData; нужен HTTPS tunnel и тест на твоём телефоне |
| Codex | Локальный `codex exec`, только приватные справки; нет платного API-fallback |
| Reddit | Read-only OAuth-адаптер написан, **выключен до реального разрешения Reddit**; refresh токена ещё не реализован |
| Публикация из Telegram | **Не реализована.** Сейчас скопировать свой текст → открыть площадку → отправить вручную |
| Computer Use | Описан как следующий отдельный адаптер, не реализован и не объявлен работающим |
| Автотесты | 54 локальных теста проходят; живые Telegram/Codex/Reddit не проверены |

Полностью бесплатный автоматический Reddit-мониторинг не обещается: право доступа для маркетингового сценария зависит от Reddit, а не от наличия кода. Reddit Pro бесплатен, но не является экспортируемой лентой для бота. Подробнее: [исследование](docs/RESEARCH.md).

## Запуск

Из папки `research-dump/threadscout`:

```bash
python3 --version
python3 -m unittest discover -s tests -v
python3 -m threadscout demo
cp .env.example .env
# Заполнить токен НОВОГО бота локально; отправить этому боту /start.
python3 -m threadscout whoami
# Внести свой числовой Telegram ID в TELEGRAM_OWNER_ID.
python3 -m threadscout doctor
python3 -m threadscout run
```

Первый путь не требует Mini App, Codex или Reddit. Отправь боту `/demo`, затем `/scan`, `/status`, `/digest`. Демо-карточки вымышлены и никогда не попадают в настоящую очередь.

`/scan` ставит обновление в очередь; проверяй завершение в `/status`. Нулевые результаты и ошибка источника показываются отдельно. На macOS/Linux зависимости Python устанавливать не нужно; на Windows без системной IANA-базы времени может понадобиться `tzdata` или WSL.

### Подключить существующий Codex

```bash
codex login
codex login status
codex exec --help
```

После проверки входа через ChatGPT поставь `USE_CODEX=1` в `.env` и перезапусти бота. Нажатие «Почему я» запустит приватную справку; ежедневный отбор работает без модели. Код принудительно выбирает ChatGPT-auth и не переключается на платный API. Недоступный CLI, неподдерживаемые флаги, лимит или ошибка → обычная справка по правилам. Реальный запуск этого адаптера ещё нужно проверить локально. [S10–S12](docs/SOURCES.md)

### Основные команды

`/digest` — до трёх карточек за запрос. `/scan` — сбор. `/status` — ошибки и состояние. `/demo` — интерфейс без источников. `/add URL` — конкретная ветка; без доступа Reddit сохраняется только закладка. `/cancel` — отключить прежние запросы ввода.

После «Написать самому» отвечай именно на сообщение бота: так текст сохраняется к правильной ветке. «Готово» означает твою отметку, не факт публикации. Короткий ответ копируется нативной кнопкой; для длинного есть текстовые блоки и опциональный Mini App. [S13](docs/SOURCES.md)

По умолчанию сбор ежечасный, подборка после 19:00 Europe/Berlin, окно поиска 48 часов; меняется в `config.json`. Компьютер и процесс должны работать. После долгого сна полный пропущенный поток не восстанавливается. Не запускай два процесса `run` или отдельный `digest` одновременно.
